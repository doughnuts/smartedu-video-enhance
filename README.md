# 智慧教育·教师研修 视频增强

国家智慧教育公共服务平台（www.smartedu.cn）视频播放增强油猴脚本：倍速播放、后台播放、拖动进度条。

## 功能

- 倍速播放（0.75x – 16x）
- 后台播放（切走标签页不暂停）
- 拖动进度条

## 安装

1. 浏览器安装 Tampermonkey（油猴）；
2. 点击本仓库的 `smartedu-video-enhance.user.js`，在打开页面点右上角 **Raw**，油猴会自动弹出「安装此脚本」确认框；
3. 打开课程页并刷新，右下角出现「⚡ 研修视频增强」面板即可使用。
